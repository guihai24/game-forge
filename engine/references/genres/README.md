# 玩法库

给 agent 在需求梳理时挑方案用，**不给用户看分类表**。用户只需要回答"玩起来对不对"。

## 这个库怎么用

1. 用户说了题材（"裁员""相亲""考研"）
2. agent 从下面挑 **3 个** 玩法，配上**这个题材的场景化描述**
3. 每个都出**能玩的最小原型**（30–60 秒，无美术）
4. 用户各玩一遍，说"哪个对 / 哪里不对"
5. 选定后才写 brief、进正式开发

**不要问用户"你想选哪个 core mechanic"**——用户不懂黑话，也想象不出手感。
问法只有一种：**"这个玩起来对不对？"**

---

## 两个正交的维度（不要混）

任何一款游戏都是这两者的组合：

```
核心玩法（玩家反复做什么）  ×  节奏（一局多长、多难停）
```

- `genre`（玩法）：动作 / 解谜 / 策略 / 模拟 / 赌运气 / 反应 …
- `pace`（节奏）：30 秒 / 3 分钟 / 十几分钟

**"休闲"不是玩法，是节奏。** 消消乐是「解谜 + 休闲」，五子棋是「棋牌 + 休闲」——
同一个节奏，完全不同的玩法。把它们混成一个字段，是之前所有同质化的源头。

## 六大玩法原型

每一类都给了：**玩家动作**、**好的体验长什么样**、**适合什么题材**、**原型骨架怎么做**。

### 1. 反应 / 节奏（REFLEX）

**玩家反复做**：在一个固定的节拍上，做精确的输入。

**好的体验**：进入状态后不用想，手比脑子快。做错一拍的反馈是"再来一次"而不是"你完了"。

**适合**：紧张、专注、手忙脚乱。—— 加班地狱、地铁挤早高峰、双十一抢单

**原型骨架**：屏幕上一条判定线，方块从远处滑来，在线上按下。
命中连击递增，漏一个掉一格血。**不需要移动角色**。

**关键数值**：判定窗口（宽 = 好上手，窄 = 高手向）、连击奖励斜率、失败是否可挽回。

---

### 2. 解谜 / 观察（PUZZLE）

**玩家反复做**：看，找规律，做一次不可逆的操作，看结果。

**好的体验**："啊，原来是这样！"——那种想通了的一瞬间。做错时能看出自己哪里想错了。

**适合**：烧脑、恍然大悟、有"机关"的题材。—— 拿到离职协议找漏洞、相亲时看穿对方话术

**原型骨架**：一个棋盘/网格，玩家点一下改变局面，目标是把局面推到某个状态。
步数有限，每步都能后悔（或不能，二选一，这是核心取舍）。

**关键数值**：步数上限、是否可撤销、有没有提示。

---

### 3. 资源 / 取舍（STRATEGY）

**玩家反复做**：在两个都想要的选项里放弃一个。

**好的体验**：每个决定都疼，但每个决定都合理。回头看能说出"我当时为什么那么选"。

**适合**：荒诞、无奈、左右为难。—— 裁员名单、彩礼谈判、房贷还是辞职

**原型骨架**：每回合给 2–3 个选项，每个都明确标注代价和收益，
选完立刻看到数值变化。回合数固定（比如 10 回合），最后结算。

**关键数值**：回合数、选项之间的张力（不能有一个明显更好）。

---

### 4. 养成 / 经营（SIM）

**玩家反复做**：投一点资源，等它长大，再投。

**好的体验**：看着一个东西从无到有。中间要有"快好了"的期待感。

**适合**：踏实的、有积累感的。—— 存钱、职场升级、小店经营

**原型骨架**：几个数值条，每秒自动增长，玩家决定把资源投给哪个。
目标是 60 秒内把某个指标推到阈值。

**关键数值**：增长曲线、投入的延迟（立刻见效 = 浅，延迟 = 有规划感）。

---

### 5. 赌运气 / 心理博弈（BLUFF）

**玩家反复做**：在不完全信息下押注，然后看结果。

**好的体验**：手心出汗。赢了觉得"我算到了"，输了觉得"差一点"。

**适合**：提心吊胆、赌一把。—— 老板今天心情好不好、绩效评级

**原型骨架**：给部分信息（看到 3 张牌里的 2 张），玩家押大/小/不押，
揭示结果。押对了翻倍，押错扣分，不押保本但排名下滑。

**关键数值**：信息透明度、赔率、是否允许"跳过"。

---

### 6. 模拟 / 代入（ROLEPLAY）

**玩家反复做**：在对话框里选一句话，看对方怎么反应。

**好的体验**："这话我说不出口，但我好想说。"——代入感来自选择的真实性。

**适合**：情绪浓、有对话的题材。—— 跟 HR 谈离职、跟父母解释为什么不结婚

**原型骨架**：一个聊天窗口，对方说一句，你从 2–3 个回复里选，
对方根据你的选择改变态度值，态度归零或满值结束。

**关键数值**：态度值的变化幅度、有没有"说真话"的选项。

## 挑方案的方法

**先看题材的"情绪动作"是什么**：

| 用户想要的情绪 | 优先考虑 |
|---|---|
| 爽、发泄 | 反应、赌运气 |
| 烧脑、恍然大悟 | 解谜 |
| 无奈、左右为难 | 策略、模拟 |
| 踏实、有积累 | 养成 |
| 有代入感、想说话 | 模拟 |

**再避开重复**：跟已有游戏玩法相同的，直接排除。
（判断依据是上面这个 `genre`，不是代码相似度——今天栽在把"躲避"当成唯一选项。）

## 反例：不要这样问

```
✗ 你想选哪个：ACT / PUZZLE / STRATEGY？
✗ 核心循环是什么？核心动词是什么？
✗ 你希望是 collect-and-dodge 还是 match-3？

✓ 我做了三个能玩的版本，各 30 秒：
   第一个是抢时间按对按钮
   第二个是找房间里不对劲的地方
   第三个是在两个烂选择里挑一个
   你玩一下，哪个感觉对？
```
